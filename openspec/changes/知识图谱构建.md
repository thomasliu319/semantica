场景
面对一堆非结构化文档要回答跨文档问题："谁与项目 X 的参与者合作过"、"哪些供应商与此事件相关"。单文档无法回答，传统 RAG 检索也无法串联事实链。需要知识图谱：实体作节点、带类型的关系作边，多跳推理转化为图遍历。

SDK 调用范例
import asyncio
from typing import Literal
from pydantic import BaseModel
from cloud_agent_sdk import (
    CloudAgentClient, ManifestBuilder, RuntimeCreateOptions,
)

# Pydantic schema 约束抽取输出
class Entity(BaseModel):
    name: str
    type: Literal["PERSON", "ORGANIZATION", "LOCATION", "EVENT", "ARTIFACT"]
    description: str

class Relation(BaseModel):
    source: str
    predicate: str
    target: str

class ExtractedGraph(BaseModel):
    entities: list[Entity]
    relations: list[Relation]

async def extract_graph(documents: list[str]):
    client = CloudAgentClient(api_key="ck_xxx")

    manifest = (
        ManifestBuilder()
        .id("kg-extractor")
        .name("KG Extractor")
        .version("1.0")
        .system_prompt(open("kg_prompt.md").read())
        .build()
    )

    runtime = await client.runtimes.create(
        RuntimeCreateOptions(runtime_name="kg-job", agent_manifest=manifest)
    )
    session = runtime.sessions.default()

    graphs: list[ExtractedGraph] = []
    for doc in documents:
        # 用 prompt 显式要求 JSON schema 输出
        await session.prompt(
            f"Extract a knowledge graph from this document. Output strict JSON"
            f" matching ExtractedGraph schema.\n\n<document>{doc}</document>"
        )
        # 此处省略：解析响应文本中的 JSON 块

    # 实体消解（同 session 复用上下文）
    await session.prompt(
        "Cluster the extracted entities. Each input name appears in exactly"
        " one cluster's aliases. Use descriptions to avoid merging entities"
        " that merely share a name."
    )

    await runtime.delete()
    return graphs

asyncio.run(extract_graph([open(f"docs/{i}.md").read() for i in range(6)]))
存储
小规模：NetworkX MultiDiGraph 直接存内存，几十万边可用
大规模：迁移到 Neo4j、Neptune 或 Postgres（entities / relations / aliases 三张表）
进阶
大规模消解：先用低成本信号（姓氏、token 重叠、embedding 相似度）分块，再让 Agent 在 50-100 候选块内裁定
增量更新：新文档抽取后与现有规范实体集消解，仅添加新边
节省成本：用 Prompt Caching 缓存 schema；用 Message Batches API 享 5 折优惠
