# 营销/经营语义指标层

窗口：**2026-01～06**（H1）。对象：`dataReport/dataset/` 10 张 CSV。  
B1 仍有效：这里是**派生度量**，不是分析报告，不产达成率结论、不产名单。

机读目录：`dataReport/dataset/_semantic/metric_catalog.json`（待实现）。

## 维度（谁 / 在哪 / 何时 / 做什么）

| 维度 | 键 | 业务语义 | 基数 | 注意 |
|---|---|---|---|---|
| 业务员 | `sales_code` | 工号 | 458 | 同工号多名，聚合取 `MAX(姓名)` |
| 科室 | `fdept`（组织侧 `fdept_add`） | 预算对照键 | 见 `dept_dim` | 与区名/小区名不是一回事 |
| 产品类型 | `zprod_type` | 预算对照键 | 见 `product_dim` | 不是机型名 |

| 组织 | `forg_name`/`org_name` | 事业群 | 少量 | 默认「装备一事业群」 |
| 销售部 | `sales_dept` | 销售一部/二部 | 少量 | |

| 客户 | `kunnr_code`/`fcust_number` | 客户 | 见宽表 | 签单 vs 出货客户字段不同 |

## 度量（按业务域）

### 1. 出货（管理出机 / 考核出机）— 粒度 `ship_order_line`

| id | 中文名 | 公式 | 单位 | 不是 |
|---|---|---|---|---|
| `ship_amount_fc` | 出货不含税 | `SUM(TotalMoneyFC)` | 元 | |
| `ship_amount_fc_hs` | 出货含税 | `SUM(TotalMoneyFC_HS)` | 元 | 出机指标分子 |
| `ship_amount_fc_hs_wan` | 出货含税万元 | `/10000` | 万元 | 与预算同单位 |

### 2. 签单（管理签单）— 粒度 `sign_order_line`

| id | 中文名 | 公式 | 单位 |
|---|---|---|---|
| `sign_amount_fc` | 签单不含税 | `SUM(TotalMoneyFc)` | 元 |
| `sign_amount_fc_hs` | 签单含税 | `SUM(TotalMoneyFc_HS)` | 元 |
| `sign_amount_fc_hs_wan` | 签单含税万元 | `/10000` | 万元 |

### 3. 预算 — 粒度 `dept_budget_month` / `product_budget_month`

| id | 中文名 | 字段 | 单位 |
|---|---|---|---|
| `management_ship_budget_hs` | 管理出机预算 | `Management_Ship_Budget_Hs` | 万元 |
| `assessment_ship_budget_hs` | 考核出机预算 | `Assessment_Ship_Budget_Hs` | 万元 |
| `management_signed_contract_hs` | 管理签单预算 | `Management_SignedContract_Hs` | 万元 |

### 4. 达成类（派生，B4 `fdept_all`）

| id | 中文名 | 公式 | 不是 |
|---|---|---|---|
| `management_ship_achieve_pct` | 管理出机达成率 | `Σ出货含税万元 / Σ管理出机预算` | 单行金额直接除 |
| `assessment_ship_achieve_pct` | 考核出机达成率 | `Σ出货含税万元 / Σ考核出机预算` | |
| `management_sign_achieve_pct` | 管理签单达成率 | `Σ签单含税万元 / Σ管理签单预算` | |
| `sign_ship_ratio` | 签单/出货比 | `Σ签单含税 / Σ出货含税` | 达成率 |

达成口径：按 `Fdept` 全量、不过滤 `User_role`；除数为 0 → null。

**达成率四要素**（B6/B7/B8/B3，缺一即错，详见 [design.md](./design.md)）：

| # | 要素 | 过滤 | 漏掉的后果 |
|---|---|---|---|
| 1 | 组织 | `org_scope = 'in_scope'` | 228.6% |
| 2 | 机型 | `zprod_type ∈ 预算覆盖 6 类` | 148.2% |
| 3 | 科室 | `fdept` 非空 | 103.3% |
| 4 | 单位 | 分子 `/10000` | 差 10⁴ 倍 |

四要素全满足 → 考核出机 130.6%、管理出机 91.1%、管理签单 103.2%。

### 5. 人员行为（B4 例外：`User_role='业务'`）

| id | 中文名 | 公式 | 粒度 |
|---|---|---|---|
| `consecutive_no_sign_count` | 连续不签单人数 | 按 `SalesCode` 聚合，截至某月无签单 | 业务员 |
| `consecutive_no_ship_count` | 连续未出机人数 | 同上，出货 | 业务员 |

同工号多名：按 `SalesCode` 聚合，姓名取 `MAX`。

## 派生指标（基础度量自由组合）

| id | 公式 | 粒度特征 |
|---|---|---|
| `ship_per_emp` | `Σ出货含税 / nunique(业务员)` | 人均出机 |
| `sign_per_emp` | `Σ签单含税 / nunique(业务员)` | 人均签单 |
| `product_type_share` | `Σ出货含税 / Σ总出货含税` | 产品类型份额 |
| `area_share` | `Σ出货含税 / Σ总出货含税` | 区域份额 |
| `ship_mom` | `(m_t − m_{t−1}) / m_{t−1}` | 仅自然月，1 月为 null |

## 推荐切片

1. 科室 × 月：管理/考核出机、管理签单达成率
2. 产品类型 × 月：考核出机达成（`fill_product_budget` 对照 `ZPROD_TYPE`）
3. 业务员 × 月：连续不签单/未出机
4. 区域 × 月：出机/签单份额
5. 客户 × 机型：出货明细（签单 `KunnrCode`、出货 `fcust_number`）

不要切片：把出货不含税 `TotalMoneyFC` 与含税 `TotalMoneyFC_HS` 混在同一达成口径里。
