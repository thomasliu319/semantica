# 营销数据分析助手 — 交接说明

面向 Dify 的「自然语言 → SQL Server 查数 → 分析报告」智能体。本目录供同事接手时快速了解**数据源、连接与仓库真源**；完整口径以仓库根目录业务 md 为准。

---

## 项目一句话

用户用中文提问营销达成/行为等问题 → 工作流生成 SQL → 权限改写 → 连 `csj_dw` 查库 → 按结果写总结报告（禁止捏造数据）。

---

## 工作流主路径

```text
用户问题
  → SQL语句生成（规则：SQL语句生成V2.md）
  → SQL权限拼接（规则：SQL权限拼接.md）
  → 查库（pymssql，见「数据库连接.md」）
  → 总结输出（规则：总结输出.md）
  → 直接回复用户
```

失败时可能走 SQL 修正 / 重试查库（DSL 中另有一份相同连接配置）。

---

## 本地文件 ↔ Dify 节点

| 仓库文件 | 用途 | Dify 侧 |
|----------|------|---------|
| `SQL语句生成V2.md` | SQL 生成 system 规则 | 「SQL语句生成」节点 prompt |
| `SQL权限拼接.md` | 行级权限改写 | 权限相关 LLM 节点 |
| `总结输出.md` | 报告结构与禁止捏造 | 「总结输出」节点 |
| `话术最终版-业务测试指南.md` | 业务测试问法 | 不进 prompt，给人用 |
| `营销数据智能体-正式（营销）V2.7.0.yml` | 工作流导出快照 | 导入/对照用；|

**改规则流程（强制）**：先改仓库对应 `.md` → 再全文粘贴进 Dify 节点。只改 yml 或只改 Dify 不回写仓库，容易双源漂移。
