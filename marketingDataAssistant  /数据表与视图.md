# 数据表与视图

智能体生成 SQL **仅允许**四类对外对象；底层表/中间视图**禁止**在生成 SQL 中直接引用。  
视图构成以本节所附 **DDL（业务提供）** 为准。对外字段字典详见 [`SQL语句生成V2.md`](../SQL语句生成V2.md)。

---

## 一、对象总览

### 1.1 智能体允许查询（四类）

| 对象 | 类型 | 用途 | 金额单位 | 备注 |
|------|------|------|----------|------|
| `v_sales_order_product` | 视图 | 签单实际、人员行为、新老客户等 | **元** | 见下文 DDL |
| `v_sale_ship_order_emp_product` | 视图 | 出机/出货实际、连续未出机等 | **元** | 见下文 DDL |
| `fill_dept_budget` | 表 | 组织（科室）月度预算 | **万元** | **由业务上传** |

宽表与预算比较前：`SUM(宽表金额) / 10000` → 万元。

### 1.2 底层 / 中间对象（禁止智能体直查）

| 对象 | 类型 | 中文 | 备注 |

## 二、血缘（底 → 顶）

```text
fill_sales_dept ──LEFT JOIN── bi_vpsempinfo_month（当年当月 y1/m1）
        │
        ▼
 v_sales_emp_info
        │
        ├── FULL OUTER JOIN dw_sgning_wide_table
        │         └── LEFT JOIN ods_sap_cw_product（FmateType = ZPROD_NAME）
        │                    ▼
        │         v_sales_order_product
        │
        └── 被 LEFT JOIN ← dw_sale_order_saptest（驱动表）
                  └── LEFT JOIN ods_sap_cw_product（fmate_type = ZPROD_NAME）
                             ▼
                  v_sale_ship_order_emp_product
```

要点：

- **签单宽表**：`v_sales_emp_info` **FULL OUTER JOIN** `dw_sgning_wide_table`，再 LEFT JOIN 产品分类。
- **出货宽表**：**不是** FULL OUTER JOIN。以 `dw_sale_order_saptest` 为驱动，**LEFT JOIN** `v_sales_emp_info`，再 **LEFT JOIN** `ods_sap_cw_product`。
- 两宽表均间接依赖 `v_sales_emp_info`（其内再打 EHR 月表），引用成本高；连续不签单/未出机须**单次引用**对应宽表。

## 三、业务上传表说明

以下三张表数据由**业务上传**维护，非智能体写入：

| 表名 | 说明 |
|------|------|
| `fill_sales_dept` | 装备一事业部业务员部门架构；进入 `v_sales_emp_info` |
| `fill_dept_budget` | 科室×月预算（管理/考核出机、管理签单等） |
| `fill_product_budget` | 产品类型×月预算 |

预算字段与指标映射仍以 `SQL语句生成V2.md` 为准。达成类：`Fdept` 全量、不过滤 `User_role`；连续不签单/未出机才用 `User_role=业务` 等。

## 四、视图 DDL（csj_dw.dbo）

### 4.1 `v_sales_emp_info`（各事业部业务组织架构视图）

```sql
SELECT
    dept.SalesCode,
    dept.SalesName,
    dept.ForgName,
    dept.SalesDept,
    dept.Area,
    dept.Fdept,
    dept.SupervisorName,
    dept.Province,
    dept.AffiliationCity,
    CONVERT(VARCHAR(10), emp.entrydate, 120) AS entrydate,
    emp.grade,
    dept.EmploymentStatus,
    dept.User_role,
    dept.Sales_Employment_Date
FROM dbo.fill_sales_dept AS dept
LEFT OUTER JOIN dbo.bi_vpsempinfo_month AS emp
    ON dept.SalesCode = emp.empcode
   AND emp.y1 = YEAR(GETDATE())
   AND emp.m1 = MONTH(GETDATE());
```

### 4.3 `v_sales_order_product`（签单宽表）

```sql
SELECT
    COALESCE(emp.SalesCode, ord.SalesCode)  AS SalesCode,
    emp.SalesCode                           AS empSalesCode,
    ord.SalesCode                           AS ordSalesCode,
    COALESCE(emp.SalesName, ord.SalesName)  AS SalesName,
    emp.SalesName                           AS empSalesName,
    ord.SalesName                           AS ordSalesName,
    COALESCE(ord.Orgname, emp.ForgName)     AS Orgname,
    ord.Orgname                             AS OrdOrgname,
    emp.ForgName                            AS EmpOrgname,
    emp.SalesDept,
    emp.Area,
    emp.Area                                AS EmpArea,
    emp.Fdept,
    emp.SupervisorName,
    emp.Province,
    emp.AffiliationCity,
    emp.entrydate,
    emp.Sales_Employment_Date,
    emp.grade,
    emp.EmploymentStatus,
    emp.User_role,
    ord.SalesOrgName,
    ord.SalesDocnoDate,
    ord.Fyear, ord.Fmonth, ord.Auart, ord.AuartName, ord.Werks,
    ord.ContractName, ord.Docno, ord.DocnoNum, ord.KunnrCode,
    ord.FmateNumber, ord.FmateSeris, ord.Fqty,
    ord.TotalMoneyFc, ord.TotalMoneyFc_HS,
    pro.ZPROD_NAME, pro.ZPROD_TYPE
FROM dbo.v_sales_emp_info AS emp
FULL OUTER JOIN dbo.dw_sgning_wide_table AS ord
    ON emp.SalesCode = ord.SalesCode
LEFT OUTER JOIN dbo.ods_sap_cw_product AS pro
    ON ord.FmateType = pro.ZPROD_NAME
GROUP BY
    emp.SalesCode, ord.SalesCode, emp.SalesName, ord.SalesName,
    COALESCE(ord.Orgname, emp.ForgName), ord.Orgname, emp.ForgName,
    emp.SalesDept, emp.Area, emp.Fdept, emp.SupervisorName,
    emp.Province, emp.AffiliationCity, emp.entrydate,
    emp.Sales_Employment_Date,
    emp.grade, emp.EmploymentStatus, emp.User_role,
    ord.SalesOrgName, ord.SalesDocnoDate, ord.Fyear, ord.Fmonth,
    ord.Auart, ord.AuartName, ord.Werks, ord.ContractName, ord.Docno,
    ord.DocnoNum, ord.KunnrCode, ord.FmateNumber, ord.FmateSeris,
    ord.Fqty, ord.TotalMoneyFc, ord.TotalMoneyFc_HS,
    pro.ZPROD_NAME, pro.ZPROD_TYPE;
```

## 五、指标映射与默认过滤（浓缩）

| 业务说法 | 实际 | 预算（科室，含税） |
|----------|------|-------------------|
| 管理出机 | 出货 `TotalMoneyFC_HS` | `Management_Ship_Budget_Hs` |
| 考核出机 | 出货 `TotalMoneyFC_HS` | `Assessment_Ship_Budget_Hs` |
| 管理签单 | 签单 `TotalMoneyFC_HS` / `TotalMoneyFc_HS` | `Management_SignedContract_Hs` |

默认：`Orgname LIKE N'装备一事业%'`、排除固定工号、默认含税、默认不含 3C。  
达成：`Fdept` 全量、不过滤领导；连续不签单/未出机：`User_role=业务`、按 `SalesCode` 聚合。详见 `SQL语句生成V2.md`。
